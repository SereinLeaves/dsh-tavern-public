# dsh-tavern 个人修改版

基于 [tk553521/dsh-tavern](https://github.com/tk553521/dsh-tavern) 0.1.0 的个人修改与可恢复备份。原插件及贡献者拥有其原有版权，原始 MIT 许可证完整保留在 LICENSE 和发行包目录中。官方翻译组件的来源、版本与许可证保留在 extras/tavern-cot-scope/。

本仓库独立维护个人修改，默认提交到本仓库的 codex/personal 分支。后续变更在本仓库记录。

## 当前备份内容

- 会话初始化、历史恢复以及编辑、重试、回复版本切换的修复。
- 旧中文角色卡、世界书和预设保存兼容，以及旧资料删除保护。
- 现有会话的设置入口，可调整角色、世界书、预设模型与模式。
- 按会话和角色隔离的经历记忆，以及分支变化后的记忆暂停。
- 运行中角色设定及世界书更新。
- 酒馆展开的思考内容通过官方翻译组件显示简体中文，并可切回原文。
- 角色头像与点击出场功能目前处于后续开发阶段，完成验证后另行提交。

## 目录和验证

dist/dsh-tavern/ 保存实际安装版本的运行文件；UPSTREAM-README.md 保存上游使用说明。snapshot.json 记录所备份发行文件的 SHA-256。scripts/ 中的检查仅使用虚构夹具和临时目录。

运行验证：

```sh
npm test
```

当前发行快照来自已安装包，部分修改直接发生在构建后的 JavaScript 文件中。原始 TypeScript 源码及可重建开发环境尚未整合。lib/index.d.ts 是原包类型声明，新增个人功能以运行文件和回归检查为准。

## 恢复使用

这份快照针对 DSH Desktop 0.2.2-rc.1 的既有安装。先运行验证，再正常退出 DSH，备份当前已安装的插件目录，将 dist/dsh-tavern/lib/ 下的 index.js 和 client.js 复制到已安装 dsh-tavern 的 lib/ 目录，重新打开 DSH。

extras/tavern-cot-scope/ 是与酒馆配套的官方翻译组件个人修改版。按原插件配置将此组件注册为独立条目，provider 设为 bing、targetLanguage 设为 zh。依赖由匹配版本的 DSH profile 提供。翻译会将用户展开的酒馆思考片段发送到所选翻译服务。

角色卡、聊天日志、世界书、经历内容、头像、账号凭据与个人 profile 配置应另行本地备份。应用恢复操作需要以目标机器当前安装为准，避免覆盖新版本或正在写入的文件。
